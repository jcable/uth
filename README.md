# uth

Uth helps you practice reading aloud and get an indication of how understandable you are.

## Development 

Uth was created by Julian Cable. The architecture was suggested by Claude AI and Claude created the code for the API server and the initial Android app.

Further coding used Github Copilot. Copilot selected ChatGPT as the engine on most occasions.

Uth is coded in dart and built using flutter. The initial version targets Android phones but other platforms can be added.

## Technology

The audio is transcribed to text and the transcript compared with the user's script.

The speech transcripts are generated by a fine-tuned Whisper model for Scottish Gaelic based on the research presented in the paper 
["Practitioner’s Guide to Building SR Models for Low-Resource Languages: Case Study on Scottish Gaelic" (Klejch, Lamb, Bell, 2025)](https://www.isca-archive.org/interspeech_2025/klejch25_interspeech.html).

The Gaelic Automatic Speech Recognition model and API were developed by the University of Edinburgh with funding from the Scottish Government. They are licensed under the Open Government License v3.0.

The model can be found at https://huggingface.co/eist-edinburgh/whisper-large-v3-turbo-gaelic-ct2-v2.

The model is hosted at modal.com.

See also https://www.clarin.ac.uk/eist-gaelic-speech-recognition-tool

## Use

The home screen is a list of scripts entered by the user by typing or pasting the text in.

Texts can be deleted from the list and exported, along with any transcript.

Selecting a script shows the text in a scrollable view.

The user presses a record button and reads the pasted text, scrolling down when necessary.

The user can choose to:

1. play the recording
2. re-record
3. submit the recording for transcription.

The returned transcript is associated with the current text and saved alongside it.

The transcript is compared with the script, ignoring any differences of capitalisation, white space, full stops, commas, quotation marks, question marks and exclamation marks.

Where the transcript differs from the script, the script is highlighted in green. The transcript for a section is shown after the original and highlighted in red. The transcript text can be hidden to help the user read the script, or parts of it, out again.

Tapping on a green section of text opens the text in a popup window where the individual words can be looked up to help the user know how to pronounce them.

The user can select a section of the text and record new audio for transcription for that section. The relevant section of the full transcript is replaced with the new transcript and the transcript is compared again with the script and the highlighting updated.

The audio samples are discarded after transcription. This might change in the future.

Elements of the text can be selected and copied to copy buffer.
